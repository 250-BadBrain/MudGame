# 副本流程记录

本文记录当前已实现副本的实际游玩流程。全部副本彼此独立、可重复进入，每次进入都会重置敌人与机关状态。设计总纲见 [huangyi_dungeon_redesign.md](huangyi_dungeon_redesign.md)。

## 通用规则

- **章节链解锁**：order 1 永久开放；order N 在任一 order N-1 副本达成一次 100% 完成度后解锁（通关旗标 `dungeon_cleared_<id>` 驱动）。副本规划为数十至上百章，当前 7 章仅为前期内容。
- 完成度由加权目标构成（击杀为主），核心头目被击败后完成度才可满额；可选目标标记 `optional`，不计入 100% 分母。
- 关键敌人存活时会封锁后续出口；敌对 NPC 不因玩家进房自动开战。
- 解谜至多两个，推荐多步机关链（状态机推进 + 关键处选择题，选错可回退重试）；解谜收益可以指向 Boss 战（破招）。
- 故事 NPC（船夫、纪千千等）以 `combatMode: "protected"` 受保护，不可被击杀或切磋；纯氛围 NPC（怒蛟伤兵）标记 `nonCombat`。
- 结算时经验/潜能/金钱按完成度比例发放，物品与旗标仅在 100% 时发放。
- 战斗中可以使用药品（金创药等），是副本推进的核心消耗品；死亡复活后虚弱 5 分钟（战斗属性减半）。
- 奖励数值与装备/残页掉落总表见[收益与经济设计](../design/economy_design.md) 1.3。

## 荒庙夜雨（洛阳轶事 · order 1）

- ID：`abandoned_temple_rain`
- 路线：庙门 → 无相殿 → 后院雨廊
- 流程：击败三名流寇（50%），追至后院雨廊（15%），击败蒙面刺客（35%），夺回染血密信。
- 奖励：经验 180 / 潜能 120 / 钱 60 / 染血密信。

## 扬子江惊变（大唐双龙传 · order 2）

- ID：`datang_changshengjue`
- 路线：扬子渡口 → 芦苇荡 → 沉船浅滩 → 江心洲 → 北岸柳林
- 流程：渡口听老船夫说明宇文阀封渡始末；沿江杀穿武士（拦路）、巡江刀手、先锋；北岸柳林斩宇文化及，向傅君婥复命。
- 可选解谜（1）：沉船浅滩"打捞铁匣"得《长生诀》残页（可选完成度 10%）。
- 记忆点：护送傅君婥渡江；残页是打捞出来的，不是杀出来的。
- 奖励：经验 260 / 潜能 180 / 钱 80。

## 怒蛟帮夜战（覆雨翻云 · order 3）

- ID：`fuyu_nujiao`
- 路线：水寨栈桥 → 前寨栅门 → 演武场 → 聚义庭 → 聚义厅
- 流程：听哨兵通报敌情；三段波次拦路（刀手群 / 枪卫+细作 / 刀手群）后抵达聚义厅；聚义厅 1v3 击退方夜羽（defeat 模式，力竭退走，不死亡）。
- 解谜（0）：纯战斗波次防守。
- 记忆点：细作不在正路拦路，而是藏在演武场暗处放火，必须揪出来。
- 奖励：经验 340 / 潜能 230 / 钱 100；完成旗标 `fuyu_nujiao_completed`（终局解锁条件之一）。

## 惊雁宫夺图（破碎虚空 · order 4）

- ID：`posui_jingyan`
- 路线：宫门石阶 → 前殿回廊 → 星槎大殿 → 剑冢长廊 → 图录大殿
- 流程：两段石像卫拦截；星槎大殿三步星图机关开启北门；剑冢石剑卫；图录大殿与战神幻影决战。
- 解谜（1，三步链）：观察穹顶星图 → 对照殿壁星官壁画（发现北斗斗柄指向与穹顶有偏差）→ 转动石门星盘并选择方向；选错则星盘卡死弹回、退回"对照"步骤重试，无惩罚。正确开启石门获得"看破"旗标，对战神幻影触发破招（攻/防/命中显著削弱）——解谜直接改变 Boss 战难度。
- 记忆点：星图是通往图录的钥匙，也是破幻影的钥匙。
- 奖励：经验 380 / 潜能 260 / 钱 100 / 战神图录摹本；完成旗标 `posui_jingyan_completed`（终局解锁条件之二）。

## 边荒夜护（边荒传说 · order 5）

- ID：`bianhuang_escort`
- 路线：边荒集北门 → 官道荒林 → 破败驿站 → 断魂石桥 → 荒野渡口
- 流程：北门听纪千千交托行程；游骑、弓手、骑督三段截击（拦路）；渡口斩燕军前锋督将（30%），抵达渡口计入完成度（10%）。
- 解谜（0）：纯护送突围战。
- 记忆点：弓手据残墙箭雨封路，正面无掩体，先手很关键。
- 奖励：经验 400 / 潜能 270 / 钱 120。

## 杨公宝库（大唐双龙传 · order 6）

- ID：`datang_yanggong`
- 路线：库门甬道 → 机关厅 → 千机廊 → 天地棋枰 → 藏兵库 → 宝库大殿
- 流程：杀穿突厥武士；机关厅"转动机关盘"开北门；千机廊杀阴癸妖女；天地棋枰"落子破局"开北门；藏兵库击碎石人卫；大殿斩杀突厥第一高手康鞘利。
- 解谜（2，本组上限）：机关盘、棋局，均为单步动作，错误无惩罚。
- 记忆点：鲁妙子批注"弃子争先，以拙破巧"——棋局答案写在门楣上，考验的是注意细节。
- 奖励：经验 460 / 潜能 300 / 钱 150 / 宝库金珠。

## 拦江一战·残影（覆雨翻云 · order 7，终局）

- ID：`fuyu_lanjiang`
- 解锁：需要 `fuyu_nujiao_completed` 与 `posui_jingyan_completed` 两个旗标（对应副本 100% 结算）。
- 路线：大江渡头 → 江心舟阵 → 拦江战台
- 流程：渡头听老船翁讲当年一战（讲古中给出提示）；江心舟阵击散江雾幻兵；战台挑战庞斑残影。
- 解谜（1）：江心舟阵"静观江涛"——获得"看破庞斑气机"旗标，决战时残影被破招大幅削弱；不看也可以强杀，但这是终局的赌点。
- 记忆点：传说宗师只以残影应战，破招来自对江潮的观察而非数值。
- 奖励：经验 700 / 潜能 450 / 钱 300。

## 竟陵之围（大唐双龙传 · order 8，第二卷开启）

- ID：`datang_jingling`
- 路线：竟陵南门 → 城头箭楼 → 内城街巷 → 府库机枢房 →（东门瓮城 / 水门暗渠，二择一）→ 城外芦荡
- 流程：方泽流交代围城形势；三段城防拦路（南门长矛手、城头云梯锐士、街巷细作）；机枢房协助鲁妙子校准守城弩机（装填→校尺→顺风修正，选错重试）；择一条突围线杀出（东线强攻铁骑 / 水线清伏兵护民夫）；城外芦荡斩江淮军先锋都督。寇仲、徐子陵在城头并肩（双龙客串）。
- 解谜（1）：守城弩机两步+选择。锁定后决战时都督被弩机重创（破招）——解谜直接改变 Boss 战难度。
- 独占分支：东线"击溃铁骑×3"与水线"清除伏兵×2"同组只计其一（各 25%），两条线均可 100% 结算，可重开体验另一线。
- 记忆点：那一箭要等风向——校准好的守城弩机会替你钉住敌将的将旗。
- 奖励：经验 820 / 潜能 520 / 钱 340 / 古铜残片×3。

## 天刀试炼（大唐双龙传 · order 9，武道试炼类型首发）

- ID：`datang_tiandao`
- 路线：刀堂前院 → 木人阵廊 → 刀意石壁 → 心镜水榭 → 演武场
- 流程：宋阀管事说明三关之约；击碎四具木人；石壁悟刀（临摹→自悟→选择刀道气质，刚/灵皆为正解）；水榭照见并斩落心魔幻影；演武场接宋缺三刀（力竭收刀即胜，不死）。
- 解谜（1）：悟刀，双解选择无错误路径，两种刀道气质皆得"刀意通明"旗标——对决宋缺时被点破刀路（攻/命中/防削弱）。
- 记忆点：刀无定式——石壁不问对错，宋缺的三刀只认有没有把自己的刀悟透。
- 奖励：经验 940 / 潜能 610 / 钱 400 / 天刀残页×1（参悟《天刀八诀》，灰袍老者可传授至 120 级）。
