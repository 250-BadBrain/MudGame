# 黄易武侠副本重设计（战斗主导版）

本文档取代已删除的《寻秦记前六副本重设计》，是当前章节副本的设计总纲。

## 一、设计原则


1. **副本 = 一个具体地点的独立小故事**：直接用小说中的典型片段命名（扬子江、怒蛟帮、惊雁宫……），不需要读过长篇也能看懂。
2. **战斗为主**：完成度由击杀加权推进（"杀一个敌人加多少进度"），敌人拦路、多波次、守关头目、终局 Boss。
3. **解谜克制**：每副本最多 2 个解谜，大多数 1 个或没有；解谜必须是具体动作（搜索、转机关、观星图），不做长时间推理。
4. **错误有代价不死档**：拦路敌人杀不完就走不过去，但不存在无解死局。
5. **可选内容改变收益**：可选目标（打捞、隐藏动作）提供额外完成度或破招优势，不做主线必需。
6. **每副本一个"可复述的记忆点"**：观星破幻影、数潮破残影、机关宝库、车轮护送。

## 三、逐副本设计

### 1. 荒庙夜雨（保留，order 1）

3 房：庙门 → 无相殿 → 后院雨廊。杀 3 流寇开门，杀蒙面刺客夺回密信。无解谜。

### 2. 扬子江惊变（order 2）

**片段**：《大唐双龙传》开篇，宇文阀沿江追杀携《长生诀》北上的高丽女傅君婥。
**地图**：扬子渡口 → 芦苇荡 → 沉船浅滩 → 江心洲 → 北岸柳林。
**流程**：渡口老船夫交代情由 → 逐段杀穿宇文阀武士/刀手/先锋（拦路）→ 北岸斩宇文化及，傅君婥告别。
**解谜（1）**：沉船浅滩"打捞铁匣"——可选打捞《长生诀》残页（可选完成度）。
**完成度**：武士×4（30）+ 刀手（10）+ 先锋（20）+ 宇文化及（40）＝100；可选残页 10。
**奖励**：经验 260 / 潜能 180 / 钱 80。

### 3. 怒蛟帮夜战（order 3）

**片段**：《覆雨翻云》，魔师宫少主方夜羽夜袭怒蛟帮总舵。
**地图**：水寨栈桥 → 前寨栅门 → 演武场 → 聚义庭 → 聚义厅。
**流程**：哨兵交代敌情 → 三段波次拦路（刀手群/枪卫+细作/刀手群）→ 聚义厅 1v3 击退方夜羽（defeat 模式，力竭退走不死）。
**解谜（0）**：纯战斗波次防守。
**完成度**：刀手×6（30）+ 枪卫×2（15）+ 细作（15）+ 双剑卫×2（10）+ 方夜羽（30）＝100。
**奖励**：经验 340 / 潜能 230 / 钱 100；完成旗标（终局解锁条件之一）。

### 4. 惊雁宫夺图（order 4）

**片段**：《破碎虚空》，传鹰等七奇客探惊雁宫夺《战神图录》。
**地图**：宫门石阶 → 前殿回廊 → 星槎大殿 → 剑冢长廊 → 图录大殿。
**流程**：石像卫、石剑卫两段拦截 → 星槎大殿三步星图机关开启北门 → 图录大殿与战神幻影决战。
**解谜（1，三步链）**：观察穹顶星图 → 对照殿壁画 → 转动石门星盘（选择题：向左/向右；选错弹回退至上一步重试）。**记忆点**：开启石门获得"看破"旗标，会"看破"战神幻影的招路，决战时幻影被破招削弱——解谜收益指向 Boss 战。
**完成度**：石像卫×4（30）+ 石剑卫×2（20）+ 星图（10）+ 战神幻影（40）＝100。
**奖励**：经验 380 / 潜能 260 / 钱 100 / 物品《战神图录摹本》；完成旗标（终局解锁条件之二）。

### 5. 边荒夜护（order 5）

**片段**：《边荒传说》，燕军铁骑在边荒集外截击南下名妓纪千千。
**地图**：边荒集北门 → 官道荒林 → 破败驿站 → 断魂石桥 → 荒野渡口。
**流程**：纪千千登船前托付 → 游骑/弓手/骑督三段截击（拦路）→ 渡口斩燕军前锋督将。
**解谜（0）**：纯护送突围战。
**完成度**：游骑×4（25）+ 弓手×3（20）+ 骑督（15）+ 督将（30）+ 抵达渡口（10）＝100。
**奖励**：经验 400 / 潜能 270 / 钱 120。

### 6. 杨公宝库（order 6）

**片段**：《大唐双龙传》，鲁妙子机关宝库，突厥高手康鞘利受魔门之托入库夺宝。
**地图**：库门甬道 → 机关厅 → 千机廊 → 天地棋枰 → 藏兵库 → 宝库大殿。
**流程**：杀穿突厥武士 → 机关厅"转动机关盘"开北门 → 千机廊杀阴癸妖女 → 天地棋枰"落子破局"开北门 → 藏兵库石人卫 → 大殿斩康鞘利。
**解谜（2，本组上限）**：机关盘、棋局，均为单步状态机，错误无惩罚。
**完成度**：武士×2（10）+ 妖女×2（15）+ 石人卫×3（15）+ 机关（10）+ 棋局（10）+ 康鞘利（40）＝100。
**奖励**：经验 460 / 潜能 300 / 钱 150 / 物品《宝库金珠》。

### 7. 拦江一战·残影（order 7，终局）

**片段**：《覆雨翻云》终章，浪翻云与庞斑拦江一战。江湖秘术将庞斑残影凝于江心战台，供后人挑战传说宗师（符合世界观文档"传说宗师只作残影试炼"）。
**地图**：大江渡头 → 江心舟阵 → 拦江战台。
**流程**：老船翁讲古并留下暗示 → 江心舟阵杀江雾幻兵 → 战台挑战庞斑残影。
**解谜（1）**：江心舟阵"静观江涛"——获得"看破庞斑气机"旗标，决战时残影被破招大幅削弱。不看也强杀（这是终局的赌点）。
**解锁**：需要《怒蛟帮夜战》与《惊雁宫夺图》均 100% 完成。
**完成度**：幻兵×2（20）+ 观涛（10）+ 庞斑残影（70）＝100。
**奖励**：经验 700 / 潜能 450 / 钱 300。

### 8. 竟陵之围（order 8，第二卷开启）

**片段**：《大唐双龙传》，杜伏威江淮军围攻竟陵，城主方泽流死守孤城，隐士鲁妙子以守城器械助防，寇仲、徐子陵亦在城头并肩。呼应 order-6《杨公宝库》中"鲁妙子批注"的伏笔。
**地图**：竟陵南门 → 城头箭楼 → 内城街巷 → 府库机枢房 →（东门瓮城 / 水门暗渠，二择一）→ 城外芦荡。
**流程**：方泽流交代围城形势 → 南门杀长矛手、城头杀云梯锐士、街巷揪出细作（三段城防，拦路）→ 机枢房协助鲁妙子校准守城弩机 → **择一条突围线杀出**（东门瓮城强攻铁骑 / 水门暗渠清伏兵并护民夫出城）→ 城外芦荡迎战江淮军先锋都督。
**解谜（1，两步+选择）**：守城弩机"装填巨矢 → 迎风校尺 → 修正扣发（选顺风东修/逆风西修）"；选错弩矢落空、退回校尺重试，无惩罚。正确锁定后决战时都督被弩机重创破招——解谜收益直接改变 Boss 战。
**独占分支（exclusiveGroup 首次启用）**：东线"击溃铁骑×3"与水线"清除渠畔伏兵×2"同属 `breakout` 组，各占 25% 完成度，**只计其一**；两条线都能达成 100% 结算，重开副本可体验另一条线（复玩价值）。
**完成度**：长矛手×3（15）+ 云梯锐士×3（15）+ 细作×2（10）+ 弩机锁定（10）+ 突围线任一（25）+ 先锋都督（25）＝100。
**奖励**：经验 820 / 潜能 520 / 钱 340 / 古铜残片×3（为后续合成预留材料）。
**Boss 数值梯度**：先锋都督 等级 28 / 气血 520（承接康鞘利 21/350 → 庞斑残影 26/470）。

### 9. 天刀试炼（order 9，武道试炼类型首发）

**片段**：《大唐双龙传》时代的宋缺乃天下用刀第一人。宋阀商队入洛，宋缺于城南别院设刀堂三日，以三关试天下用刀之人（世界设计文档"临时到访"登场模式；宋缺为规划的"中后期武道标杆"首次落地）。
**地图**：刀堂前院 → 木人阵廊 → 刀意石壁 → 心镜水榭 → 演武场。
**流程**：宋阀管事说明三关之约 → 木人阵击碎四具木人 → 刀意石壁"临摹刀痕 → 闭目自悟 → 领悟刀意（以刚为纲/以灵为要，**两种选择皆为正解**，刀无定式，仅气韵不同）→ 心镜水榭照见并斩落心魔幻影 → 演武场接宋缺三刀（defeat 模式：他力竭收刀即为通过，不死）。
**解谜（1，两步+双解选择）**：悟刀。无论刚猛还是灵动，皆得"刀意通明"旗标——与宋缺对决时被点破刀路（攻/命中/防显著削弱）。无错误路径，选择只决定玩家的刀道气质文案。
**完成度**：木人×4（20）+ 悟刀（15）+ 心魔（25）+ 接下三刀（40）＝100。
**奖励**：经验 940 / 潜能 610 / 钱 400 / 天刀残页×1（第三门进阶武学《天刀八诀》的参悟道具）。
**Boss 数值**：宋缺 等级 32 / 气血 650（defeat 模式，留四分之一气血收刀）；心魔幻影 等级 24 / 气血 420。

### 10. 洛水风浪（order 10，主世界支线）

**片段**：竟陵围城一役后，洛水水匪趁漕运空虚劫掠商旅。你从南市盐仓渡口得知匪巢所在，受盐帮之托清剿鹞子帮水寨，救出被掳船工。
**地图**：水寨外围 → 芦荡栅门 → 中军快船。
**流程**：外围清剿水匪（拦路）→ 栅门破两拨守卫 → 快船解救被掳船工（剧情动作两步）→ 斩杀鹞子帮头目。
**解谜（0）**：支线以战斗+救援叙事为主。
**完成度**：水匪×4（30）+ 救出船工（20）+ 鹞子帮头目（50）＝100。
**奖励**：经验 760 / 潜能 480 / 钱 250 / 盐帮声望 +20（《漕运疑云》后日谈：船号对上了账）。
**Boss 数值**：鹞子帮头目 等级 26 / 气血 560；水匪 等级 12~16。

### 11. 飞马牧场（order 11，魔门线转正）

**片段**：《大唐双龙传》中段，阴癸派觊觎飞马牧场的马匹与地脉财富。商秀珣主事牧场，婠婠亲至——南市素帕、流民营童谣里的"白衣女子"现出真身，魔门线从传闻转正。
**地图**：牧场大门 → 马厩场 → 桑田阡陌 → 天马厩 → 主宅庭院。
**流程**：商秀珣交代阴癸派夜袭 → 马厩杀阴葵刺客（拦路）→ 桑田清剿杀手 → 天马厩"安抚惊马"（吹哨稳群开北门）→ 主宅庭院迎战婠婠（defeat 模式：裙裾一拂飘然退去，不死）→ 战后可拾取她遗落的玉匣（天魔策残页，可选）。
**解谜（1）**：安抚惊马（单步动作，为可选玉匣的拾取铺垫氛围，非门槛）。
**完成度**：刺客×2（20）+ 杀手×2（20）+ 安抚惊马（15）+ 逼退婠婠（45）＝100；玉匣为可选目标（不计分母）。
**奖励**：经验 1,060 / 潜能 660 / 钱 380。
**Boss 数值**：婠婠 等级 30 / 气血 600（defeat 模式，留四分之一血退场）；阴葵刺客 17 级、杀手 19 级。

### 12. 长安风云（order 12，双圣会长安）

**片段**：《大唐双龙传》长安篇——师妃暄携和氏璧入京，慈航静斋与阴癸派之争摆上台面。飞马牧场退走的婠婠与阴癸派元老边不负先后入长安，玩家受托协防。
**地图**：长安西市 → 天街 → 东市坊巷 → 和春亭 → 慈航别院。
**流程**：茶博士递话（师妃暄相邀）→ 天街、坊巷两段阴葵死士拦路 → 和春亭听师妃暄讲禅（获"禅音净心"旗标）→ 别院助阵：边不负强夺璧匣，被禅音所摄（破招：攻/命中/防削弱），师妃暄与他斗法，你从旁截杀 → 战后师妃暄赠小还丹为谢（可选）。
**解谜（1）**：听禅（两步：入亭参谒 → 凝神听禅；正确后决战破招）。
**完成度**：死士×4（30）+ 听禅（15）+ 逐走边不负（55）＝100；谢礼为可选目标。
**奖励**：经验 1,180 / 潜能 720 / 钱 420。
**Boss 数值**：边不负 等级 32 / 气血 700（defeat 模式力竭遁走）；阴葵死士 20 级；师妃暄 protected。

## 四、实现约定

- 副本 NPC 全部 `instanceOnly: true`，ID 前缀按副本：`csj_`（长生诀）、`nj_`（怒蛟）、`jyg_`（惊雁宫）、`bh_`（边荒）、`yg_`（杨公宝库）、`lj_`（拦江）、`jl_`（竟陵）、`td_`（天刀）。
- 隐藏势力：`moshi_palace`（魔师宫）、`yan_army`（燕军）、`turkic_khan`（突厥）、`yinkui_sect`（阴癸派）、`jianghuai_army`（江淮军）、`song_clan`（宋阀山城）。
