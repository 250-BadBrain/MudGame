## 首次发布

从仓库根目录执行；本次未执行远程步骤：

```powershell
.\deploy.bat -BuildOnly
.\deploy.bat -StageOnly
.\deploy.bat -MigrateMartialArts
```

首次V2发布须携带`-MigrateMartialArts`。StageOnly输出逐角色只读预览；正式发布先停服落盘、完整备份，再迁移并启动。出现异常或健康检查失败恢复匹配旧程序及迁移前存档，并另存失败版本数据。没有迁移选项且发现旧角色时在停服前拒绝。前端也需要更新发布，后端脚本不部署前端。

独立迁移工具为`MudGame-server/resources/migrations/migrate_martial_v2.py`，默认仅预览，应用还须`--apply --server-stopped`；逐角色报告包含退款、技能、装备和前后哈希。旧分卷按实际投入合并，超上限或未达新资格的投入退潜能；重复/退役秘籍按旧回收价补偿，装备冲突退回背包。旧版绝学持有记录不能绕过指定传承。启动器拒绝未迁旧档或迁移锁，防止新程序静默重写。

旧档映射快照为`resources/migrations/martial_v1.json`。`scripts/rebuild_martial_v2_resources.py`是本次一次性资源编排记录，检测快照存在会拒绝重跑，后续扩展直接维护JSON资源。打包排除Python字节码缓存；备份排除迁移过程锁，备份恢复后可正常启动。
