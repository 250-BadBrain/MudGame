基线0004c58。复用现有135物品、313 NPC、38武学、41任务、8世界、65公共房间与78副本及其房间，集合不增删；本轮只增加既有对话/机关选项、条件、旗标和指引元数据。不改掉率、奖励、武学来源、经济、战斗、安全区与快速完成规则。用户已授权本会话直接实施并同步玩家文档，不推送部署，不访问正式存档。

## 三件城市旧事的后续

原互斥结论保留，已做选择的旧角色可以继续；新增后续须本人明确询问，不自动作决定。两个立场各有可用情报，没有唯一正确立场，也不锁核心传承。共同流程：询问既有证人、携凭证作选择→向该分支人物追问→在原相关副本使用情报。情报/武学不跳过敌人、终局判断或结算；没有情报同样可以通关。

| 既有事件 | 选择后的追问对象 | 影响现有副本的操作 |
|---|---|---|
| 洛阳·密信应怎样入卷 | 匿名保全→秦三娘；保留原卷→韩录事 | 《运河追击》匿名线在断缆纤道辨出转运绳迹，替代第一观察；原卷线在双闸绞盘核对抄存更次，替代回码头核簿，仍需观察绳迹与闸盘 |
| 巴蜀·栈道应先修还是先封 | 留窄路→剑阁驿丞；封危险段→酒娘 | 《绝壁悬栈》修路线在承重双桩按驿丞方案分担承重，替代两步支撑；封存线在风剪悬栈以封段记录辨旧接头，替代第一观察，仍需支撑与终局判断 |
| 扬州·三联账怎样才算对清 | 匿名实账→船娘；三联封存→程盐商 | 《盐帮内乱》匿名线在三联账房以水路证词核脚夫联，替代第二观察；封存线在分盐旧秤以原封记录查破角盐引，替代第一观察，仍须另一观察与最终取舍 |

情报在每次实例都可使用，只记录实际使用过的见闻，不产物品或钱。不要求继续持有原凭证，凭证已在城中作决定时查验；进入副本仍遵守原解锁条件。新增后续人物不会因自动交谈而被认定已追问。

《运河追击》的共同终局选项改写为“核清更次后开下游闸”，不再声称所有角色都必须回码头，普通折返、原卷旁注和踏浪诀比对都能完成同一核验。

## 六门已有武学参与探索

| 副本 / 场景 | 已学武学至少1级 | 操作和作用 |
|---|---|---|
| 运河追击 / 双闸绞盘 | 踏浪诀 | 先看绳迹，再沿纤道比对潮痕与更次，替代回码头核簿 |
| 沉船探秘 / 压舱石室 | 混元功 | 先查通气孔，再以绵劲试梁并稳住受力，替代两步手工支撑 |
| 剑首之争 / 折枝剑径 | 奔雷剑法 | 从平整枝口辨出收锋，替代第一观察；不自动选择剑首立场 |
| 绝壁悬栈 / 承重双桩 | 血战刀法 | 比对磨断和刀断的纤维，替代第二观察，不斩承重绳 |
| 战神遗卷 / 三相图壁 | 悟真篇 | 按异文辨轮廓的正倒关系，替代第二观察，仍须两步解图 |
| 唐门试炼 / 错簧回廊 | 铁壁功 | 以护架试探回簧而不硬接暗器，替代第一观察，仍须机台调查和顺序操作 |

采用已学知识/手法，不要求切换当前装备武学或主武器；须同时满足原武学资格（如根基20级），伪造“高级武学已学但根基缺失”不可用。不收费、不扣内力、不提供战斗属性；这些是探索动作，不是战斗技能。房间文字说明可尝试的武学；不满足时隐藏按钮，直接请求仍由服务端拒绝，失败不改变机关或付出物品。动作沿用房间、机关状态、前置线索和敌人阻路规则，无稀有武学强制门槛。

## 见闻的关联与下一步

在已有对话定义附加journey元数据（对应现有事件，不新增任务ID），引用已存在的证人、凭证、两个分支旗标、追问选项、实际机关。服务端从本人旗标和持有物派生进度，仍使用get_quests.journal；不新增玩家存档字段。

只有询问过事件办理者专长、任一证人专长或已做该事件选择后，才显示事件指引。尚未触发的城市事件不会预先出现在见闻中。按缺证人→缺凭证/回办理者选择→追问所选分支人物→原章节解锁/现场可选情报→已使用情报或自行完成相关章节显示下一步，并给出城市、房间和人物名。未选分支、对立结论和终局答案不进入指引；不自动寻路、传送或跳过副本解锁。

界面在“令→见闻”优先展示已知事件的关联卡片（进度、相关章节、下一步），历史记录继续折叠回看。使用普通解法完成相关章也给出完成反馈，不诱导玩家为打勾重复刷本。新武学和情报解法只在实际使用后进入历史。
