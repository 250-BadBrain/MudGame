# 收益与经济设计

本文档定义三种核心资源（**经验** = 技能上限、**潜能** = 技能等级、**银两** = 商品）的全部来源、数值与消耗出口。修改任何收益数值时，先改本文档，再落实到代码与资源文件。

## 0. 设计原则

1. **公共世界不通过战斗产出资源**：世界中的 NPC 战斗（旧坊暗巷等非安全区）只提供风险与剧情氛围，击杀不掉落、不给经验潜能，以维持世界状态的稳定。
2. **副本是主要资源来源**：经验、潜能、银两、关键物品均以副本产出为主，按副本章节梯度递增。
3. **世界提供专门的采集/劳作地点**：低强度、有冷却的补充来源，用于闲暇时段与新手起步，收益远低于副本。
4. **死亡有代价**：复活后虚弱 5 分钟（战斗属性减半，见《公式文档》1.5），使副本中的死亡决策有分量。

**独占分支目标（order 8 起）**：同一 `exclusiveGroup` 的目标只计其一（如竟陵东线强攻/水线暗渠各占 25%），两条线均可达成 100% 结算，为副本提供复玩价值。

**章节链解锁**：副本规划为数十至上百章的长期内容。order 1 永久开放；order N 在任一 order N-1 的副本达成一次 100% 完成度后解锁（`dungeon_cleared_<id>` 旗标驱动）。副本列表按 order 排序，未解锁章节显示前置副本名。

**非战斗 NPC**：剧情型 NPC（如怒蛟帮伤兵）标记 `nonCombat`，不可被攻击或切磋。

**机关与选择**：多步机关链与剧情选择是副本解谜的推荐形态（如惊雁宫星图"观察→对照→转盘选择"，选错可重试）；目标可标记 `optional`（不计入 100% 完成度分母，作为额外奖励）。

**战斗用药**：药品（金创药等）可在战斗中使用，是副本战斗的核心消耗品与银两出口；无使用冷却，受背包存量约束。

## 3. 死亡与虚弱

- 副本内死亡：`relive` 后回到副本检查点，**气血/内力恢复至上限 50%**，虚弱 300 秒（战斗属性减半）。
- 世界内死亡：`relive` 后回洛阳天津桥（ly_00），同样虚弱。
- 虚弱可正常移动、采集、交谈、买货，但战斗能力减半——鼓励玩家在虚弱期做经济行为而非立刻再战。

## 4. 后续预留（当前不实现）

- 更多进阶武学与对应残页道具（按新副本内容需要重新添加）。
