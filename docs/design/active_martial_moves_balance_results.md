# 主动招式平衡验证报告

状态：**部分覆盖，未宣布"平衡完成"**。本报告记录2026-10-29首轮自动化对比的结果与复现方法；完整九路线矩阵与三策略比较仍是后续任务（见文末"未覆盖项"）。

## 方法

- 测试：`MudGame-server/internal/manager/runtime_manager_combat_moves_balance_test.go`
- 场景：序8《竟陵之围》（jl_vanguard_commander）、序38《天刀试炼殿》（宋缺残影）、序71《太虚幻境之主》（tx3_boss），各3种子
- 构建：与既有平衡基线 `TestV2RoutesAgainstRepresentativeBosses` 同源的同预算角色（同经验/潜能/装备/内力修满），覆盖拳脚、刀、枪三条路线
- 策略：`auto_only`（仅普攻+按需小还丹）对比 `moves`（出招CD就绪即按视图顺序施放攻击型主动，普攻与用药照常）
- 随机：`combatRandom` 按 种子×1 注入；时钟注入，无真实等待
- 原始记录：`artifacts/moves_balance.json`（Git忽略，54场逐场数据）

## 结论

- **无发布阻断违规**：没有任一"仅普攻可通关"的配置因加入主动而胜率下降超过20个百分点或降至50%以下；未出现无响应窗口秒杀同预算满血目标。
- 主动招式把序38的战斗时长缩短约一半（13→7轮），序71刀/枪路线把原本0/3的失利配置翻为3/3——主动额外DPS收益明确。序71拳脚仍为2/3（两种策略相同），与该路线无攻击型主动可用的低谷一致，属既有路线强度问题而非主动引入的退化。
- 单场最短5轮（序38刀），无永久僵局；用药消耗与既有基线一致。
