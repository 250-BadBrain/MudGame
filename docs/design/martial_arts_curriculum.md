# 武学谱系设计（流派·段位·传承）

本文是**武学库的总谱**：兵器流派划分、段位覆盖模型、全部技能/老师/秘籍来源的清单与扩展原则。数值规则以 [formulas.md](formulas.md) 3.3 为准，收益与来源以 [economy_design.md](economy_design.md) 1.3.1 为准。

## 一、设计原则（2026-10 与维护者确认）

1. **内功是人人必修的根基，不属武器流派**：基本内功与内功类秘籍（长生诀等）是独立于一切兵器的必修线——所有流派都建立在它之上。流派/段位的划分只针对武器。
2. **主流武器段位覆盖完整**：刀、剑两条武器主线从入门到宗师每一档都有可学内容——基础技能（入门）→ 中阶武学（强化）→ 秘籍进阶（残页参悟）→ 宗师亲传（击败宗师级 NPC 后请教）。
3. **小众兵器种类多、秘籍少、段位不要求完整**：枪、鞭、锏、钩等小众兵器各有基础技能与传授人，但通常只有入门段；特殊秘籍稀少，随副本内容逐步补充。
4. **传承有仪式感**：秘籍必须"残页参悟 + 传承人深造"；宗师级必须"战胜本人，得其亲传"——宋缺败而不死，留在演武场，胜者可请教。
5. **技能类型只有两种机制**：BASIC（老师直接教）与 ADVANCED（残页参悟 + 老师深造）。段位差异靠**老师上限**与**加成强度**表达，不新增机制。

## 二、段位模型

| 段位 | 技能类型 | 加成强度（每 10 级） | 获得方式 | 上限区间 | 前置门槛 |
|---|---|---|---|---|---|
| 入门 | BASIC | 单一属性 +1 | 世界老师（武馆/军府/盐帮/密探）直接请教 | 150~300（随老师） | — |
| 中阶 | BASIC | 单属性 +2 或双属性 +1/+1 | 少数名师（当前为军府秦校尉） | 200 | — |
| 秘籍进阶 | ADVANCED | 2~3 项属性，强于中阶 | 副本残页参悟 1 级 → 灰袍老者深造 | 120（灰袍） | 前置基本武功 ≥ 指定等级 |
| 宗师亲传 | BASIC/ADVANCED | 同秘籍 | 击败宗师级 NPC 后向本人请教 | 320+（随宗师） | 同秘籍前置 |

> 经验共享上限仍是全局闸门（formulas 3.1）：主线十副本通关约 60 级上限，宗师段位是长期目标。
>
> **装备规则**：每种基本武功是一个秘籍槽位，可学多本同系秘籍但**只能装备一本**，仅装备中的秘籍参与属性加成（按秘籍自身等级计算，见 formulas 3.3 装备规则）。前置门槛即槽位归属：天刀八诀的前置是基本刀法，就只能装进基本刀法的槽。

**秘籍段位阶梯（按前置等级划分）**：入门秘籍（前置 20 级）→ 中阶秘籍（前置 40 级：天刀八诀、修罗刀法、太乙剑法）→ 高阶秘籍（前置 60 级，预留）→ 宗师秘籍（前置 80 级 + 宗师亲传）。

## 六、扩展原则

- 新增秘籍 = 技能 JSON + 残页道具 + 副本掉落（可选目标或 100% 奖励）+ 灰袍老者传授上限，四件一处不缺。
- 新增宗师 = 高数值 NPC（defeat 或可反复挑战）+ teachSkills 高上限 + 文案点明"胜而请教"。
- **小众兵器不为了段位完整而灌水**——留白即内容，等对应的副本/势力线再补。
