# 既有资源内容深化：不扩资源目录

用户目标：不增加物品、地图、NPC等资源，丰富既有内容，让资源有独有职责和用途。基线71085f3：135物品、313 NPC、38武学、41任务定义（38规范项）、8世界、65公共房间、78副本；所有这些ID集合及副本房间ID冻结。新增对话选项、机关状态、调查动作和叙事旗标是复用这些实体，不新增任务、首领、货币或通关奖励。

## 深化原则

1. 通用商店/基础教学保留便利性；独特性来自人物专属的证据解读、地点线索和章节判断，不能靠删除其他商店强迫跑图。
2. 每件物品有一个可查的出示对象、具体解读与后续意义。装备可在穿戴状态下出示，凭证不消耗、不改变强化；材料的炼制用途和秘本的参悟门槛保留。不用涨属性/加奖励冒充内容。
3. 每个公共房间提供在地线索，连接该地人物/附近既有章节；原有搜索旗标和任务目标不覆盖。NPC专长、物品描述明确告诉玩家下一步去哪里，获得的见闻可以在任务面板回看。
4. 无出场的既有NPC接回对应城镇或既有章节，重复的旧首领占位改为见证人/机关顾问，不再凭同名第二个Boss凑数。NPC数量不变；人物保护、敌对被动和安全区规则不变。
5. 原标记薄关的40章中，38个通用开门关重写入口/过程/终局叙事、机关步骤和选择；双龙会、护送商队保留其原战斗结构，补充专属复盘。采用调查推理、先后顺序、双证互校、取舍和器物辅助等交互，保留原ID、击败目标和奖励预算；错误提供具体反馈，可恢复，不暗扣钱、不强制自动开战。
6. 原有38关加上述2个战斗关，共40关保留已有主流程，补入与本章矛盾有关的可选复盘/后记和既有物品关联。不会给每关强塞同一道谜题。满通关、武学来源、15%掉落和免费快速完成语义保持；新增纯叙事动作不产额外钱/物品，不加入quickRewards。

## 机制补齐

- 对话支持explicit选项（只在玩家明确选择时执行），复用一次性历史，不能靠反复Talk自动选择证据/立场。增加requires.flags、presentItems（背包+合法装备）、skills；不影响原takeItems的实际背包扣除。
- 机关增加requiredFlags与presentItems，用于城中情报/物品辅助的可选解法；主解法不依赖15%稀有掉落，避免第一次通关被刷装备阻塞。所有需要的信息在本次副本的观察动作中也能获得。
- 见闻按已发生的调查/明确选择收录，完整保留响应，不能重新读出尚未取得的解法。在既有任务面板的“见闻”标签展示，不增加新任务定义或强制每日清单。器物解读提供可核验的线索，不提前叙述尚未亲历的终局。
- 交谈响应必须下发dialogue选项；修复原Talk处理器丢掉该字段、导致网页看不到明确选项的问题。真实协议和浏览器都要核对按钮存在，不能只直接调用已知optionId。
- 不同分支用旗标互斥，实例内步骤用puzzleStates；失败不写成功旗标，不重复掉落，不绕过房间/待选项检查。凭证出示必须本人持有，不接受请求伪造。
- 新增观察对话不使原可战斗的NPC自动受保护；显式kill模式保留其原战斗身份，商人、老师、任务人物及protected仍受保护。器物辅助按钮只在本次副本主人真实满足持有/解读条件时显示，避免铺满所有未持有器物。

## 验收与留存

保存冻结ID清单和逐资源用途报告。校验没有新增/删除实体ID、无闲置NPC、物品出示对象可达、章节解法状态可达、没有把稀有物品加入必经门槛，奖励及武学分级不变。对所有扩写薄关运行正解/错误恢复/缺线索拒绝/伪造分支拒绝测试，早期原流程回归；抽查不同机制真实WebSocket和网页入口、见闻回看。补齐玩家手册、NPC专长及器物用途目录，执行Go build/vet/test、前端test/lint/build、Python迁移部署回归和手册生成/check。只作本地中文提交，不推送部署。

后期标记按事实更新：完成了独特交互的章节标为enriched并展示玩法提示；该标记只表示本轮已扩写，不把配置校验当成人工走遍全部分支。没有完成的条目继续明确标needs_depth。
