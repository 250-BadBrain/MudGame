# 属性与战斗公式（武学 V2）

本页是V2源码的数值权威；当前为本地实施版本，线上需随前后端与旧存档迁移一起发布。[完整设计](martial_arts_v2_proposal.md)与[审计依据](martial_arts_v2_balance_review.md)保留设计背景。

## 1. 基础属性与资源

创角五属性臂力、根骨、身法、悟性、心志合计80。属性生效先合并基础、永久成长、当前基本功与合法装备；然后重算资源和衍生属性，不复用持久化Derived叠加旧值。

```text
MaxMP = max(50, 5 × (悟性+心志)) + 基本内功×10 + 当前内功/装备额外上限
有效已修内力 = min(永久TrainedMaxMP, MaxMP)
MaxHP = 60 + 根骨×4 + ceil(有效已修内力 × (基本内功30% + 当前长生诀额外比例)) + 直接气血加成
MaxSpirit = max(60, (悟性+心志)×3) + 装备额外上限
攻击 = 10 + 臂力×2 + floor(身法/2) + 直接攻击加成
防御 = 5 + 根骨×2 + floor(臂力/2) + floor(心志/2) + 直接防御加成
命中 = 50 + 悟性×2 + 身法 + 直接命中加成
招架 = 30 + 臂力 + 悟性 + floor(身法/2) + 直接招架加成
躲闪 = 30 + 身法×2 + floor(悟性/2) + 直接躲闪加成
先手 = 60 + 身法 + floor(悟性/2) + 直接先手加成
```

基本内功已学时提供固定30%转化；长生诀额外比例为15%×min(长生等级,100)/100，合计最高45%。先夹有效内力、后转血；查询不修改永久已修内力。换功/换装备只夹紧当前HP/MP，不回满，也不删除永久打坐成果。仅创角时一次性按最终上限满血，死亡/重登不套用此初始化。

## 2. 战斗

状态tick 1秒，战斗tick 2秒；每轮双方按实时先手出手，生死战中已倒下者不再出手。先手不等于攻速或额外攻击次数，预留attackSpeed不参与结算。

```text
命中率 = clamp(攻击方命中/(攻击方命中+防守方躲闪), 15%, 95%)
招架率 = clamp(防守方招架/(防守方招架+攻击方命中), 0%, 60%)
基础伤害 = max(2, 攻击 - floor(对方防御/3) + 战斗修正)
战斗修正 = 生死战14，切磋8
伤害波动 = 基础伤害×随机整数[90,110]/100，整数截断
暴击概率 = clamp(1%+合法技能/装备暴击加成, 0%, 25%)，保留小数
暴击伤害×2，招架成功再将伤害减半并截断
```

切磋须双方均空闲且满有效HP，玩家和NPC均适用。单次伤害最多为受击方有效MaxHP/5且最多扣到1HP；任何一方降到20%认输线时立即结束，取消尚未执行的反击。NPC切磋结束后无论胜负回满，玩家保留战后气血。安全区不能对玩家发起攻击或强制切磋；区外离线玩家不免战。NPC默认被动。defeat类型首领在生死挑战中降至25%气血即认负，立即取消其尚未发生的反击；不要求先打至0再恢复25%。保护NPC仍不可挑战。死亡复活后虚弱300秒，攻击、防御、命中、躲闪、招架、先手各减半；资源上限不减半。副本实例销毁或服务重启不取消DEAD/0HP，仍须复活。

## 3. 修炼与潜能

技能经验上限＝20＋10×floor(cuberoot(总经验/40))，以整数阈值40×root³校正浮点边界。基本功上限取经验上限；命名武学上限再取对应基本功当前等级的较小值。

升到目标L级花费的潜能，每20级一档：1、2、4、7、11、16、23、32、44、60、80、105、135、170、210；超过300级使用ceil(L³/128000)。入门免费1级，之后精确扣费。

每10秒最多投入10＋悟真篇加成，允许一个周期跨多个等级。保留未满一级的进度，不扣达到上限后的剩余预算，不把未用预算保存成资源。1→100花499潜能、纯修炼500秒；悟真100预算12时420秒，均以余额与等级上限足够为前提。

## 5. 恢复、用药与强化

每10秒打坐：当前内力未满，回复15＋floor(基本内功/2)＋混元回复加成；已满时，永久已修内力增长max(1,ceil(基本内功/10))，不超过当前MaxMP。临时MaxMP低于永久已修值时停止增长，不倒扣永久值。

打坐和疗伤只从空闲状态开始，开始时不立即恢复，也不扣内力；首个完整10秒才结算，反复开始/停止不能加速。疗伤每10秒恢复20HP、消耗8MP，满血或内力不足时停止。恢复药和干粮共享10秒服务端冷却，战斗内外一致；重连、换场景、换药不能绕过，失败不扣物品也不延长冷却。

死亡不能通过停止、交谈、退出副本改变状态。复活按当前有效MaxHP及有效已修内力各恢复一半，永久已修内力保留；300秒虚弱不变。普通退出副本在战斗或死亡时拒绝；战斗撤离消耗烟尘粉，不回血，副本按当前进度结算，不足100%不给满通关物品和旗标。

强化保留0～5级与既有费用/每效果键每级+2规则，但只对当前合法装备生效，背包或已卸下的强化物品不贡献属性。装备与武学的换装/卸下都要求空闲。

## 6. 实现位置

- `model/skill_progression.go`：整数经验阈值、逐级潜能。
- `manager/runtime_manager_martial.go`：统一资格、修炼上限、预算结算与五位置。
- `manager/runtime_manager_effective.go`：属性顺序、有效已修内力、装备过滤。
- `manager/runtime_manager_player.go`：老师入门、秘本、打坐/疗伤、用药冷却。
- `manager/runtime_manager_combat.go`：独立命中/招架概率、小数暴击和轮次。
