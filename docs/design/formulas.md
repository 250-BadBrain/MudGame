# 属性与战斗公式文档

本文档是数值公式的唯一权威来源。**修改任何公式时，先改本文档，再落实到代码**（代码位置在文末对照表中注明）。

## 1. 属性体系

### 1.1 基础属性（创角分配，总和 80）

| 属性 | 作用 |
|---|---|
| 臂力 Strength | 攻击、招架 |
| 根骨 Constitution | 气血上限、防御 |
| 身法 Agility | 攻击、命中、躲闪、招架、先手 |
| 悟性 Perception | 命中、内力上限、心神上限、先手 |
| 心志 Willpower | 防御、内力上限、心神上限 |

魅力、福禄：创角随机 17~25，当前无实际作用（预留）。

### 1.2 属性生效链路（重要）

代码中存在两层公式，**实际生效的是第二层**：

1. `NormalizeAttributes`（存档兜底层）：给缺失字段填默认值。其中 `MaxHP = max(80, 根骨×5)` 等公式**仅在存档数据缺字段时生效**，不代表实际数值。
2. `effectiveAttributesForPlayerNoLock`（玩家实际层数）：
   - 气血上限 `MaxHP = 60 + 根骨 × 4`（本次重新设计，替代原先强制 80 使根骨无效的问题）+ 内功转化（见 1.4）
   - 战斗衍生属性清零后重组：`最终值 = 四维衍生公式 + 技能加成 + 装备加成`
   - NPC 不走此链路，NPC 数值直接来自模板的 `NormalizeAttributes`（NPC 气血 = max(80, 根骨×5)）

### 1.3 战斗衍生公式（由四维计算）

```
攻击   = 10 + 臂力×2 + 身法÷2        （下限 1）
命中   = 50 + 悟性×2 + 身法          （下限 1）
防御   = 5 + 根骨×2 + 臂力÷2 + 心志÷2（下限 1）
招架   = 30 + 臂力 + 悟性 + 身法÷2    （下限 1）
躲闪   = 30 + 身法×2 + 悟性÷2        （下限 1）
先手   = 60 + 身法 + 悟性÷2
```

### 1.4 资源上限与成长

```
内力绝对上限 MaxMP       = max(50, (悟性+心志)×5) + 内功等级×10
内力当前上限 TrainedMaxMP = 打坐修炼积累（每 10 秒 +1），不超过 MaxMP
                          存档缺失时兜底 = min(MaxMP, max(30, MaxMP÷2))
气血上限 MaxHP            = 60 + 根骨×4 + ⌈TrainedMaxMP × 0.3⌉（内功转化）
心神上限 MaxSpirit        = max(60, (悟性+心志)×3)
```

打坐：每 10 秒回复 `15 + 内功等级÷2` 点内力；内力已满时每 10 秒永久 +1 TrainedMaxMP。

### 1.5 死亡虚弱（本次新增）

死亡后复活（`relive`）会获得 **300 秒（5 分钟）虚弱**：

- 复活时气血、内力恢复至各自上限的 50%
- 虚弱期内：攻击、防御、命中、躲闪、招架、先手**全部减半**（向下取整）
- 虚弱不影响移动、采集、交谈等非战斗行为
- 虚弱到期自动恢复，无需操作

## 2. 战斗公式

战斗按 tick 推进：状态 tick 1 秒、战斗 tick 2 秒。同一次交火中先手由双方 `先手` 值决定（高者先出手）。

### 2.1 命中与招架

```
命中率   = clamp( 命中 ÷ (命中 + 对方躲闪), 45%, 95% )
招架率   = clamp( 对方招架 ÷ (对方招架 + 攻击方命中), 45%, 95% )
```

（命中判定失败 → 本次攻击落空，无伤害）

### 2.2 伤害

```
基础伤害 = max(2, 攻击 − 对方防御÷3 + 战斗修正)
战斗修正: 决斗(KILL) +14 / 切磋(SPAR) +8
波动     = 基础伤害 × (90% ~ 110% 随机)
暴击     = 概率 = 暴击率（基础 1%），伤害 ×2
招架     = 招架判定发生在暴击之后，命中招架则最终伤害 ÷2
```

### 2.3 切磋保护

切磋（SPAR）单次出手伤害上限 = 自身 MaxHP ÷ 5，避免误杀。

### 2.4 预留属性

- **攻速（AttackSpeed）**：当前基础 4，**未接入战斗时序**（战斗节奏由 tick 固定）。重新设计方向：攻速应参与先手或引入回合内连击，待战斗系统改版时落地。
- 暴击率成长来源稀疏（仅暗器 +1%），待进阶武学补充。

## 3. 成长与经验公式

### 3.1 技能等级上限（由总经验决定）

```
技能等级上限 = 20 + 10 × root，其中 root = 经验的经验曲线序号
经验曲线    : 所需经验 = 40 × root³        （因子由 250 调整为 40，本次重新设计）
```

| root | 累计经验 | 技能上限 |
|---|---|---|
| 1 | 40 | 30 |
| 2 | 320 | 40 |
| 3 | 1,080 | 50 |
| 4 | 2,560 | 60 |
| 5 | 5,000 | 70 |
| 8 | 20,480 | 100 |
| 12 | 69,120 | 140 |

调整理由：旧因子 250 下解锁 100 级技能需 128,000 经验（主线七副本通关一遍约 2,720 经验，需重复刷数百次），成长完全断档；新因子下主线通关一遍（约 2,720 经验）+ 少量重复即可触及 60 级上限，后续章节继续推进。

### 3.2 技能升级潜能消耗

```
升到第 L 级消耗潜能 = cost[(L-1) ÷ 20]   （每 20 级一档）
cost 档位表: 1, 2, 4, 7, 11, 16, 23, 32, 44, 60, 80, 105, 135, 170, 210
（超过 300 级: ⌈L³ ÷ 128000⌉）
```

1 → 100 级累计约 500 潜能；100 → 200 级累计约 3,260 潜能。学习速度：每 10 秒注入 10 点潜能（受当前潜能余额与老师等级、经验上限约束）。

### 3.3 技能加成规则（技能 → 属性成长）

**加成规则**（完整技能谱见《[武学谱系设计](martial_arts_curriculum.md)》）：

- **入门（BASIC 武器类）**：每 10 级单一属性 +1（刀/枪→攻击，剑/钩→命中，锏→招架，鞭→躲闪，暗器→命中+暴击各 1，棍→攻击+招架各 1）。
- **入门（基础通用）**：拳脚→后天臂力 +1；轻功→后天身法 +1；招架→招架 +1；读书识字→悟性检定 +1；内功→内力绝对上限每级 +10、气血上限获得 TrainedMaxMP×30% 转化。
- **中阶（BASIC）**：单属性 +2（血战刀法：攻击）或双属性 +1/+1（奔雷剑法：攻击+命中）。
- **打坐恢复加成**：`meditate_recovery_per_10_levels` 键按秘籍装备规则生效，打坐每 10 秒内力恢复 = `15 + 基本内功÷2 + 装备中的打坐加成`（代码：`runtime_manager_player.go` ProcessStatusTick 打坐分支 + `runtime_manager_effective.go` MeditateRecoveryBonus）。
- **秘籍进阶（ADVANCED，残页参悟 + 灰袍老者深造，上限 120）**：学习有前置门槛（`requirements.prerequisite`：前置基本武功 + 最低等级）。
- **装备规则（2026-10 设计确认）**：秘籍必须**装备到其前置基本武功上才生效**——每种基本武功是一个装备槽，可学多本秘籍但同槽只能装备一本；加成按**秘籍自身练习等级**计算（天刀八诀练到 50 级就按 50 级加成），与槽位基本武功的等级无关；换装立即生效。

| 武学 | 加成 |
|---|---|
| 长生诀 | 内力绝对上限每级 +15；气血上限获得 TrainedMaxMP×50% 转化 |
| 混元功 | 内力绝对上限每级 +8；打坐内力恢复每 10 级 +3（打坐强化型内功） |
| 天魔策 | 内力绝对上限每级 +12；每 10 级暴击率 +1%（魔门杀伐心法） |
| 战神图录·刀法 | 每 10 级攻击 +3、暴击率 +1% |
| 天刀八诀 | 每 10 级攻击 +2、命中 +2（快而准的刀路，与战神图录的爆发取向互补） |
| 慈航剑典 | 每 10 级命中 +2、躲闪 +1（守心中正的佛门剑道） |

- **宗师亲传**：加成同其技能（如天刀八诀），差异在传授上限（宋缺 320 级）。

## 4. 经济公式

```
购买价 = 物品价值 value × 数量
出售价 = ⌊value ÷ 2⌋ × 数量（任务物品不可出售）
```

物品基准价值与收益结构见《[收益与经济设计](economy_design.md)》。

## 5. 恢复公式汇总

| 行为 | 每 10 秒 | 终止条件 |
|---|---|---|
| 打坐 | 内力 +（15 + 内功等级÷2）；满时改为 TrainedMaxMP +1 | 手动停止 / 内功上限修满 |
| 疗伤 | 气血 +20，内力 −8 | 气血满 / 内力不足 8 |
| 药品 | 金创药 +25 / 干粮 +5，**战斗中亦可使用** | 气血满 / 背包无存量 |
| 采集 | 无（结束时一次结算） | 30 秒后结算 |
| 帮工 | 无（结束时一次结算） | 60 秒后结算 |
