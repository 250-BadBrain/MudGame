# 技能入门与修炼（V2）

当前为V2源码规格，发布须配合旧档迁移。具体目录见[武学谱系](martial_arts_curriculum.md)，数值见[公式](formulas.md)。

## 入门

基本功由世界老师免费指导至1级；7门江湖武学由指定老师免费传授，须对应根基20。其余命名武学须取得完整秘本，并达到根基40/80/120；绝学另须读书80。指定副本100%结算写入传承资格，只解锁或同序另一关通关不算取得该传承。

参悟、装备、修炼与属性生效共享服务端资格校验；失败不扣秘本。旧客户端learn在已学情况下转为同一自主修炼流程，不另养一套老师上限。

## 自主修炼

在安全公共房间空闲时，从技能页选择已学武功修炼。每10秒投入至多10潜能，加上已装备悟真篇收益；一级完成后剩余预算可继续升级。达到经验/根基上限、余额耗尽时停止；其他中断保留已经投入的进度。老师不再维护150/200/320等永久上限。

基本功可练至经验上限；命名武学不超过对应根基当前等级。不能在副本、战斗或其他忙碌状态开始修炼；移动前先停止。退出连接停止修炼，不结算离线时间，重连不会跳过等待或丢掉已付进度。

## 生效与换装

学会不等于生效。五个命名武学位置互斥，战斗位置还要匹配唯一主武器；不兼容时显示未生效原因。空手使用基本拳脚。装备、卸下都要求空闲；换功不回血，也不减少永久已修内力。

技能页显示全目录、品阶、当前/可修等级、来源、资格缺项、当前效果与100级参考。未学条目供规划，不会自动解锁；已学条目提供修炼/停止、装备/卸下。
