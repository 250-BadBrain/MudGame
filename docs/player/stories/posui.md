### 房间与操作顺序

从「宫门石阶」进入。下列路线是从出生点到该房间的方向；有门槛时先做完门槛再移动。

**宫门石阶**（出生点）

百级石阶尽头，惊雁宫大门半开，两尊石像卫兵眼泛幽光，长戟交叉拦在门前。

人物：惊雁宫石像卫×2。

- 去北侧「前殿回廊」：击败本房间全部 惊雁宫石像卫。

**前殿回廊**（北到「前殿回廊」）

回廊立柱上刻满上古战阵，又有两尊石像卫兵自壁龛中走出，石足踏地作金石之声。

人物：惊雁宫石像卫×2。

- 去北侧「星槎大殿」：击败本房间全部 惊雁宫石像卫。

**星槎大殿**（北到「前殿回廊」 → 北到「星槎大殿」）

殿顶穹窿如夜空，缀满明珠星辰，地心一座星槎石盘缓缓转动。殿北石门上浮现星轨纹路，与穹顶遥相呼应。

- 点击「观察穹顶星图」。前置：该机关尚未操作。
- 点击「对照殿壁星官壁画」。前置：先完成「观察穹顶星图」或「向右转动星盘」。
- 点击「转动石门星盘」。前置：先完成「对照殿壁星官壁画」。
  - 选择「向左转动星盘」：你依斗柄之指向左转动星盘，机括连响，尘封的石门缓缓开启！
  - 选择「向右转动星盘」：星盘向右转了半圈便咔哒卡死、原样弹回——方向不对。你需重新对照壁画。
- 去北侧「剑冢长廊」：先完成「向左转动星盘」。

**剑冢长廊**（北到「前殿回廊」 → 北到「星槎大殿」 → 北到「剑冢长廊」）

长廊两壁插满断剑残锋，两尊持剑石像破壁而出，剑势古朴而沉重。

人物：惊雁宫石剑卫×2。

- 去北侧「图录大殿」：击败本房间全部 惊雁宫石剑卫。

**图录大殿**（北到「前殿回廊」 → 北到「星槎大殿」 → 北到「剑冢长廊」 → 北到「图录大殿」）

大殿中央悬浮着一卷流光溢彩的图录虚影，一道由殿中兵戈之气凝成的巨大幻影自影中踏步而出，气势沉沉如渊。

人物：战神幻影。

- 战神幻影破招：先取得 [《惊雁宫夺图》「向左转动星盘」现场获得](posui.md#posui_jingyan)，再发起挑战。
