# 破碎江湖：现在可以玩什么

这是一份给实际游玩者的手册。你从洛阳的小人物起步，在城市跑消息、学武、购药，通过秘境里的战斗和机关取得完整武学传承、装备与称号。主要故事来自黄易武侠的不同片段，卷名用于分类；推进门槛按一个全局章节序号判断。

**先向世界老师学基本功，在安全房间打开「技」自主修炼，再找赵横江学伏虎劲或踏浪诀，通关荒庙夜雨。长生诀放在中后期序47《行宫惊变》，开局不再取得绝学。**

> 本手册对应当前源码；武学V2已首次上线，本轮内容机制修复须另行发布后生效。一门武功不拆多卷，38门只是首版规模。

当前内容配置包括 **8 个世界、78 个副本、38项技能、135种物品、33 个称号**。世界任务共 **38 个唯一任务全部接通**，另外3个旧ID作为重复任务的兼容别名。任务目录可查看可接取、进行中、未解锁和已完成分类。部分后期副本是简短战斗关，完整剧情密度以各关实际台词为准。

## 第一次游玩：一条能照着走的路线

1. **建立角色，进入天津桥。** 看右侧「属」了解气血、内力、经验和潜能；新角色有 5000钱币（50两银）、500 潜能。底部输入框用于公开聊天，不是游戏命令行。
2. **做第一条城市任务。** 去 [南门](worlds.md#ly_south_gate)找段老镖头，反复「交谈」接「洛水传闻」；去 [洛水酒楼](worlds.md#ly_inn)与许说书交谈，回来复命。只点酒楼的「听传闻」按钮不算完成任务。
3. **选兵器，先补基础。** 在 [河洛武馆](worlds.md#ly_weapon_school)向赵横江请教拳脚、招架、刀剑等；到 [河洛书院](worlds.md#ly_academy)向柳先生请教内功。学一会儿想出发，先点「停止」。达到20级后可向对应老师学江湖武学。去 [东市](worlds.md#ly_east_market)或其他商店买兵器和药，背包里穿戴。具体商人货单见收藏目录，不必每种兵器都买。
4. **开第一关。** 点右侧「境」，选择 [荒庙夜雨](stories/luoyang.md#abandoned_temple_rain)。击败沿途流寇和刺客，后院可点「翻检刺客遗物」取得额外钱币与心得；伏虎劲改向赵横江请教；等进度 100% 后「离开副本」结算。
5. **先装备江湖武学。** 基本功20级后找指定老师入门，在「技」装备并自主修炼。名家以上的完整秘本在指定副本满通关后领取；未达门槛时不要急着换掉熟练的旧武学。
6. **继续第二关扬子江惊变。** 打捞获得药草与干粮，满通关给普通药品；长生诀的完整传承改在序47，天刀、天魔、慈航、战神也移至指定中后段。
7. **推进到第九关，体验前期主要机制。** 顺序见下表；卡关时回城学武、打坐、购药，或重刷已解锁副本积累经验和潜能。这里没有经实际游玩验证的「推荐等级」，不要把序号当成角色等级。

| 全局序号 | 副本 | 这一关有什么值得玩 |
|---|---|---|

| 2 | [扬子江惊变](stories/datang.md#datang_changshengjue) | 追击渡江、傅君婥、打捞药材、救人与渡江 |

## 想换一种体验时

- **不想一直打架**：跑 [世界调查与章节委托](quests.md)，逛八城读人物故事，采集、帮工、购药和修行。任务包含「洛水传闻」「漕运疑云」「烽燧疑警」「流民疑云」。
- **喜欢机关和解谜**：[惊雁宫夺图](stories/posui.md#posui_jingyan)、[杨公宝库](stories/datang.md#datang_yanggong)、[竟陵之围](stories/datang.md#datang_jingling)、[天刀试炼](stories/datang.md#datang_tiandao)，后面还有 [天罡北斗阵](stories/posui.md#tianbei_beidou)的七步机关。
- **喜欢剧情伏笔**：先做 [流民疑云](quests.md#refugee_rumor_case)，再看 [洛水风浪](stories/luoshui.md#liaoshui_lair)、[枯井之下](stories/luoshui.md#luoshui_kujing)的魔门线。当前任务结局只是线索，不会单独解锁这些副本，仍需满足全局章节条件。
- **喜欢选择和分支**：[竟陵之围](stories/datang.md#datang_jingling)可任选一条突围线取得满进度；[幽冥鬼市（序号 42）](stories/luoshui.md#youming_guishi)有商路、侯路、武路三套头目和取物动作，当前代码允许回头探索其他路。
- **喜欢宗师与挑战**：[天刀试炼](stories/datang.md#datang_tiandao)、[拦江一战·残影](stories/fuyu.md#fuyu_lanjiang)、[战神殿](stories/posui.md#posui_zhanshen)、[双龙会](stories/fuyu.md#shuanglong_hui)。后期有一批短篇关与宗师残影试炼。
- **喜欢收集养成**：按 [武学与物品来源表](collections.md)找完整传承、装备和称号。老师仅授入门，后续自主修炼；优先专修一种当前兵器，不用把八种兵器全部练满。
- **喜欢护送**：[边荒夜护](stories/bianhuang.md#bianhuang_escort)、[蜀道护镖](stories/datang.md#datang_shudao)、[护送商队](stories/datang.md#silk_road_hugong)。目前主要以战斗、抵达终点和剧情表现护送。

## 解锁、结算与重玩规则

- **首通后可快速完成**：某关100%通关并离开结算后，在公共世界空闲时打开「境」选择该关，点击「快速完成」。当前免费，可连续主动点击；获得正常满通关收益及登记的途中固定物品、钱币。普通结算物品独立15%掉落，每次复刷另送古铜残片2；完整秘本和剧情物品保留各自规则，临时钥匙不带出，不自动交付世界任务。不损耗也不回复气血/内力。


- [全局解锁表](unlock_order.md)列出全部 78 个副本。正常情况下，要把最近存在的前一组序号中任意一关打到 100%，并**离开副本结算**，才开放下一序号。
- 同号副本是并行选择，不要求全部通关。卷内「第几章」只作分卷展示，可能重复或与全局次序不同。
- 当前序27空缺；序28「蜀道栈桥」仍需序26完成。
- 副本可以反复进入；重进会重置房间、敌人与机关。已记录的人物通关与剧情旗标仍在。
- 进度看必需目标；可选目标不增加满进度分母，同一独占组完成一条即可。打完头目不一定满进度，进度满了也不代表现场可选奖励已经拿齐。
- 经验、潜能、银两按完成度结算；结算物品、旗标和后续解锁要 100%。现场搜索、机关直接给的物品在对应动作发生时取得。
- 活着且非战斗状态可正常离开副本；死亡先复活。战斗撤离须从背包使用烟尘粉，不回血，按当前进度结算，未满不获通关物品和旗标。
- 没有剧情 NPC 告诉你「主线已接」也可进入已解锁副本。一般不需要在对应城市找到实体入口，使用右侧「境」即可。

| 房间动作 | 搜索、打捞、机关、采集等；分支选项在消息区出现时点击 |
| 打坐 / 疗伤 / 停止 / 复活 | 修炼内力、恢复气血、中断忙碌、死亡后复活 |

## 卡住时先看这些

1. **说正在忙**：先停止学习、采集、帮工、打坐或疗伤；战斗中通常不能直接切换其他活动。
2. **门不开**：查该房间攻略的门槛，是否漏了同名敌人、机关步骤或物品；别只看头目是否倒下。
3. **剧情没有继续**：反复与同一 NPC 交谈，或完成前置目标后回来；哑婆在流民营中是独立人物，接取后向她打听再回老瘸子处复命。
4. **任务还没接下**：在「令」的可接取分类查看人物与地点，找对人交谈或点明确选项；副本型委托随对应章节解锁，不靠一句传闻自动接取。
5. **先装备江湖武学。** 基本功20级后找指定老师入门，在「技」装备并自主修炼。名家以上的完整秘本在指定副本满通关后领取；未达门槛时不要急着换掉熟练的旧武学。
6. **一进战斗就难打**：带药，战斗中可用回血药，但药和干粮共享10秒冷却；死亡复活会虚弱 300 秒，战斗属性减半。先恢复和修行，不要立刻连续挑战。
7. **制作与强化**：向药师/铁匠交谈后，点击日志里的配方按钮制作，可重复但每次扣材料；「囊」或「装」选择装备后点强化，确认费用与下级增益再提交。每级攻防命躲招先手/魅力+1、气血/内力上限+5、暴击+0.1个百分点，仅增加原有词条。旧强化有一次可选免费重置，确认后清等级并返还全部铜钱/古铜。烟尘粉现已在四家商店无限供应，250铜/包。

## 这份手册的边界

本手册按当前资源与运行时代码核对，不依赖已经过期的路线图勾选。剧情区保留游戏已写出的台词和结果，含剧透；未写出的后续没有扩写成原著故事。房间和触发已按数据交叉检查，尚未逐关实际通关验证战斗平衡。

维护时运行 `python scripts/generate_player_guide.py` 更新事实页，`python scripts/generate_player_guide.py --check` 检查漂移与内部链接。开发说明仍见 [统一开发指导](../DEVELOPMENT.md)，数值规则见 [公式文档](../design/formulas.md)。


2026-10-28规则：安全区玩家不可被攻击，区外离线玩家可以被攻击；NPC默认不主动交战。切磋须双方满血，最低留1血，NPC结束后恢复满血。物品回收为购买参考价的20%，按单件取整；制药和改铸的成品标称价值低于材料总值。
