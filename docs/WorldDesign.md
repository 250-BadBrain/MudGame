# 世界观

    以洛阳城为中心，作为玩家活动的主要场所
        城内设：
            几处商品售卖处，用以购买物品
            几处玩家工作处，用以赚取货币
            客栈
            住房（此区域各玩家独立，信息应储存在player.json中）
            衙门：追捕逃犯
            镖局：运镖
            赌场
            ...
        城外设：
            矿场：用以挖矿
            药林：用以采药
            江/湖：用以钓鱼
            ...

    此外设有六大门派：
        武当派：道家门派，以内功、剑法（飘逸、绵密）见长
        少林派：佛家门派，以内功、拳脚见长（限男性）
        峨眉派：佛家门派，以剑法（灵巧、以柔克刚）、拳脚（狠辣）见长（限女性）
        华山派：剑法大宗、以剑法（速度、爆发）为主
        丐帮：天下第一大帮，以轻功、拳脚见长
        青城派：道家门派、以轻功、**辅助**为主

    洛阳城南方设襄阳城：
        开展襄阳守城活动，抵御蒙古军队的进攻

    洛阳城西方设华山论剑台：
        用以定期举行擂台赛

    洛阳城北方设药王谷：
        此处后续开发一些玩法和奖励

    洛阳城东方设副本入口：
        东方设立一个或多个房间（待后续确定），作为副本入口
        如仅设立一个房间，则副本按难度排列
        如设立多个房间，则将副本归类，各类别中按难度排序
